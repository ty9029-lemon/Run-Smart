# 2차 UT 설문 문항 초안

1차 설문(35문항)과 비교할 수 있도록 순서와 문구를 최대한 유지했다.
표시: **[유지]** 1차와 동일 / **[수정]** 1차 결함 보완 / **[신규]** 개선 확인용.
척도는 1차와 같게 1~5점(1 전혀 아니다 ~ 5 매우 그렇다)이며, 1차 폼의 라벨을 그대로 복사해 쓴다.

## 폼 설정
- 첫 질문에서 "동의하지 않음"을 고르면 **폼 제출로 이동(종료)** 으로 분기한다. [수정]
- 픽플리는 응답자별 링크를 못 만들어 참여자 코드(A0)는 받지 않는다. 폼 설명에 `utm_source=pickply` 앱 링크를 안내하고, 앱 행동은 Unique Users 기준 집단 비교로 본다. [수정]
- 1차 참여자 제외 안내를 모집 글에 적는다.

## 1차 대비 요약
- 총 43문항(폼 수정 후): 수정 문항에 A3, A4, H2 추가, 기존 수정 6개(A0, A1 분기, C6, C8, E3, E4) / 신규 7개(F1~F7). 지표 흐름은 섹션 A~E, G, H에서 1차와 같고 신규 문항은 F에 모았다.
- 신규 문항이 7개라 응답 시간이 1차보다 1~2분 길어질 수 있다. 줄이려면 F6·F7을 먼저 뺀다.

## 분석 메모
- 비교 대상: C3(복장 도움 평균 1차 약 3.7, 23건 기준), E1, G1, G3. 표본이 작아 방향 확인용으로만 쓴다.
- A0(participantId)로 Amplitude 이벤트(`activity_disabled_clicked`, `hour_reminder`)와 응답을 개인별로 대조한다.
- 러닝 빈도(A3)로 세그먼트를 나눠 본다. 폼에서 러닝 외 활동을 묻지 않으므로 러닝 선택 여부 세그먼트는 없다.
